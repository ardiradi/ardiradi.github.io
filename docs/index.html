FlyRank AI capstone / 2026

Internship Progress Copilot API

Problem. In my self-paced internship, repeatedly checking instructions and evidence made it difficult to choose the next task.

What I built. I kept the scope to tasks, next actions, and evidence. SQLite makes the demo easy to run; background PDF jobs return HTTP 202 and expose status polling.

  • JWT-protected CRUD and SQLite persistence
  • Optional OpenAI-compatible planner with validation and caching; token logs with a zero monetary-cost placeholder
  • Retryable background report jobs with polling and idempotency
  • Prometheus request, latency, error, and runtime metrics
  • Docker, Swagger documentation, and six automated tests

What came of it. Six local tests passed on 8 October 2026. The workflow produces a structured plan and a separate PDF report. The demo uses fixed planning output; real-provider calls and time savings remain unverified.
